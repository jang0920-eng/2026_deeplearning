# 가상 스크리닝 — 필터 → 활성 예측 → 다양성 선별

ChEMBL 전체 화합물에서 도킹할 1,000개를 추리는 과정이다.
수치는 모두 실제 실행 결과이며, 각 단계의 스크립트 이름을 함께 적어 둔다.

## 깔때기 전체

| 단계 | 들어감 → 나옴 | 환경 | 도구 | 스크립트 |
|---|---|---|---|---|
| 1. 물리화학 필터 | 2,897,819 → 1,423,957 | 학교 리눅스 CPU | RDKit | `07_physchem_filter.py` |
| 2. ML 활성 예측 | 1,423,957 → 20,000 | 로컬 CPU 8스레드 | Morgan + RF | `08_ml_screen.py` |
| 3. 다양성 선별 | 10,000 → 1,000 | 로컬 CPU | sphere exclusion | `09_diversity_select.py` |
| 4. GNINA 도킹 | 1,000 → 약 100 | Colab T4 | GNINA | `11_dock_1000.ipynb` |
| 5. ADMET·용해도 | 약 100 → 15~30 | — | ADMET 예측 | (예정) |

단계마다 **다른 성격의 정보**를 쓴다. 1단계는 분자의 물리화학적 성질,
2단계는 알려진 CDK2 억제제와의 구조 유사성(학습된 패턴),
3단계는 후보들 사이의 구조적 중복, 4단계는 단백질 포켓과의 3차원 상호작용이다.
싼 계산으로 많이 걸러내고 비싼 계산을 적은 수에만 쓰는 것이 깔때기의 목적이다.

## 1단계 — 물리화학 필터

입력 `chembl_37_chemreps.txt.gz` 2,897,819개 → 통과 **1,423,957개** (49.1%).
염·혼합물은 탈락시키지 않고 가장 큰 조각만 남겨 계속 평가했다.

| 탈락 사유 | 제거 수 | 기준 |
|---|---|---|
| SMILES 파싱 실패 | 15 | 구조를 읽을 수 없음 |
| 무기 원소 포함 | 604 | 금속 착물 등 — 도킹 대상이 아님 |
| 크기 범위 밖 | 142,094 | 중원자 10 미만(조각) 또는 50 초과 |
| lead-like 위반 | 1,039,701 | MW > 450 또는 회전결합 > 7 |
| Lipinski 위반 | 149,073 | logP > 5, HBD > 5, HBA > 10 중 하나 |
| PAINS 구조 | 87,750 | 위양성을 자주 내는 구조 |
| 중복 구조 | 54,625 | 정규 SMILES 기준 동일 |

필터는 순서대로 적용했고 집계는 **처음 걸린 사유** 기준이다.
가장 많이 걸러낸 것은 lead-like(104만 개, 전체의 36%)로, ChEMBL 에 펩타이드·천연물 등
큰 분자가 많기 때문이다.

**lead-like 조건을 넣은 이유**: 도킹 소요 시간이 회전결합 수에 비례해 늘어나므로
평균 도킹 시간이 내려간다. 동시에 신약 개발 관점에서도 타당한데, 최적화 과정에서
분자량이 커지는 경향을 고려하면 출발 물질은 lead-like 영역에 두는 편이 유리하다.
계산 제약과 화학적 타당성이 같은 방향을 가리킨 선택이다.

**계획과의 차이**: 당초 1단계 출력을 약 50만 개로 예상했으나 실제로는 142만 개였다.
2단계 추론 대상이 약 3배로 늘었지만 최종 도킹 대상 1,000개는 그대로 유지했다.

## 2단계 — 활성 예측 모델 선정

### 비교한 조합
표현 3종 × 분류기 2종. 사전학습 모델은 **frozen**(파인튜닝하지 않음)으로 쓰고
encoder 출력을 masked mean pooling 한 384차원 벡터를 썼다.

| 표현 | 설명 |
|---|---|
| Morgan fingerprint | ECFP4, 2048 bit — 수업 baseline |
| ChemBERTa-10M-MTR | 10M 분자, multi-task regression 사전학습 |
| ChemBERTa-77M-MLM | 77M 분자, masked language modeling 사전학습 |

평가는 `scripts/eval_utils.py` 의 **같은 함수**로 했다.
hyperparameter 와 threshold 는 **val** 에서 고르고 **test 는 마지막에 한 번만** 평가했다.
scaler 는 train 에서만 fit 했다 (누출 방지).

### 결과 (scaffold split test 273개, 활성 159개)

| 모델 | PR-AUC | ROC-AUC | precision | recall |
|---|---|---|---|---|
| **Morgan + RF** | **0.8807** | **0.8231** | 0.7403 | 0.8428 |
| ChemBERTa-10M-MTR + RF | 0.8637 | 0.7985 | 0.7000 | 0.8365 |
| ChemBERTa-10M-MTR + LogReg | 0.8355 | 0.7875 | 0.7643 | 0.7547 |
| ChemBERTa-77M-MLM + RF | 0.8262 | 0.7446 | 0.6309 | 0.9245 |
| Morgan + LogReg | 0.7611 | 0.7345 | 0.7405 | 0.7358 |
| ChemBERTa-77M-MLM + LogReg | 0.7400 | 0.6832 | 0.6962 | 0.6918 |

**채택: Morgan fingerprint + Random Forest** (PR-AUC 0.881).

### 결과에서 읽은 것

**지문 + 트리가 트랜스포머 임베딩을 이겼다.**
학습 데이터가 2,721개로 작고, 활성 비율이 치우쳐 있으며, 화학적으로 몇 개 골격에
몰려 있다. 이런 조건에서는 부분 구조를 직접 세는 표현과 그것을 비선형으로 조합하는
트리 모델이 유리하다. 사전학습 임베딩의 장점(큰 데이터에서 배운 일반적 표현)은
파인튜닝 없이 frozen 으로 쓰면 충분히 발휘되지 않는다.

**10M-MTR > 77M-MLM — 사전학습 데이터 양보다 학습 목표가 중요했다.**
두 ChemBERTa 는 구조가 완전히 동일하다 (hidden 384, layer 3, head 12,
vocab 600, 파라미터 3.43M). 다른 것은 사전학습 데이터 규모(1,000만 vs 7,700만)와
사전학습 목표(multi-task regression vs masked language modeling)뿐이다.
구조가 통제돼 있으므로 성능 차이를 **사전학습 목표의 차이**로 돌릴 수 있다.
분자 물성을 직접 맞히도록 학습한 MTR 쪽이 활성 예측에 더 쓸 만한 표현을 만들었다.

문헌에서 MTR 이 더 좋다고 보고된 것을 보고 골랐지만, **고른 뒤 같은 split 에서
직접 검증했다.** 문헌을 근거로 선택하고 끝내지 않았다는 점이 중요하다.

### ⚠ EF 를 모델 비교 지표로 쓸 수 없었다

EF(enrichment factor)는 가상 스크리닝의 표준 지표이지만 **이 test 에서는 쓸 수 없다.**
test 활성 비율이 58.2%이므로 EF 의 이론적 최대값은 1 / 0.582 = **1.717**이다.
상위를 전부 활성으로 맞혀도 이 값을 넘지 못하고, 실제로 RF 두 개가 천장에 붙었다
(EF 5% = 1.717). 지표가 모델을 구분하지 못하는 상태다.

그래서 모델 비교는 PR-AUC·ROC-AUC 로 했다.
**지표를 그대로 쓰지 않고 적용 조건을 먼저 확인한 사례다.**

EF 자체는 활성 비율이 낮은 실제 스크리닝에서 의미가 있다.
그 조건을 만들어 측정한 결과가 아래 2단계 적용 결과에 있다.
