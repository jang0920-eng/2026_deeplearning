# 데이터 준비

## 타겟
CDK2 (CHEMBL301, Homo sapiens, SINGLE PROTEIN)

### 질환 맥락
CDK4/6 억제제 내성 HR+/HER2− 전이성 유방암.
CDK4/6 억제제와 내분비 치료가 HR+ 전이성 유방암의 표준 치료이나
대부분 환자가 내성을 획득하며, 그 기전이 cyclin E-CDK2 활성화이다.
내성 종양은 세포주기 의존성이 CDK2로 이동하므로 CDK2가 유효한 표적이 된다.

## 결정 사항과 근거

**세 지표(IC50 / Ki / Kd) 통합**
IC50 단독으로는 데이터가 부족하여 통합. 세 지표는 측정 방식이 달라
엄밀히 동일 척도가 아니며, 이로 인한 오차를 감수한 선택이다.

**부등호 데이터 제외**
`>10000 nM` 형태의 1,727건(32%)은 정확한 수치가 아니어서 회귀 학습에 부적합.
다만 확실한 비활성 사례이므로, 모델 성능이 부족할 경우
비활성 라벨로 재활용해 데이터를 약 4,400건까지 확대할 수 있다.

**활성 기준 pActivity 6.0 (IC50 1 μM)**
신약 후보 스크리닝에서 통용되는 기준.

**로그 공간 중앙값 통합**
동일 분자의 반복 측정은 pActivity(로그 스케일)의 중앙값으로 통합.
농도의 산술평균이 아닌 기하평균에 해당하며, 활성 데이터 처리의 표준 방식이다.

## 단백질 구조 선정

**선정: 3RPR** (1.75 Å, 리간드 25Z, chain A 단독)
- 관측 잔기 282 / SEQRES 306, 물 분자 217개
- 결손 구간: 37-44, 155-162

**탈락 사유**
| PDB | 해상도 | 탈락 사유 |
|---|---|---|
| 6INL | 1.75 Å | 결손 구간 148-162가 포켓 잔기 Asp145 직후에 위치 |
| 5L2W | 2.80 Å | 해상도 부족, cyclin E 동반으로 불필요하게 복잡 (B사슬 57-87 결손) |

**포켓 잔기 (리간드 5 Å 이내, 21개)**
Ile10, Gly11, Glu12, Gly13, Val18, Ala31, Lys33, Val64, Phe80, Glu81,
Phe82, Leu83, His84, Gln85, Asp86, Lys89, Gln131, Asn132, Leu134,
Ala144, Asp145
→ CDK2의 전형적인 ATP 결합 부위. 세 구조에서 거의 동일하게 관측됨.

**도킹 박스 (GNINA 설정)**
```
center_x = 92.37   size_x = 16.1
center_y = 80.29   size_y = 15.8
center_z = -47.95  size_z = 16.5
```
리간드 25Z의 중원자 바운딩 박스에 8 Å 여유를 적용한 값.

**유의 사항**
3RPR의 결손 구간 37-44는 포켓 잔기로부터 서열상 4잔기 거리에 있다.
도킹 결과에 이상이 관찰될 경우 해당 구간의 모델링 보완을 고려한다.

## 보고서 작성 시 참고
- 데이터 정제 단계별 제거 건수는 깔때기(funnel) 시각화의 1단계 자료로 사용한다.
- 세 지표 통합에 따른 오차 가능성은 한계로 명시한다.
- 5L2W의 dinaciclib은 임상 화합물이므로 최종 후보와의 비교 대상으로 활용한다.
