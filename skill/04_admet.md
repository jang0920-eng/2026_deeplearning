# 04. ADMET 예측 — 도킹 상위 100개에서 최종 후보 추리기

깔때기 5단계. 입력은 4단계 도킹 결과에서 Vina·CNNaffinity 순위 평균으로 뽑은
상위 100개(`experiment/11_docking/11_top_for_admet.csv`)이고,
출력은 최종 우선순위 15~30개다.

실행 코드: `scripts/13_admet.py`
결과: `experiment/13_admet/`

---

## 1. 왜 이 단계를 넣는가

도킹 점수는 **표적에 얼마나 잘 붙을지**만 본다. 약이 되는지는 다른 문제다.
개발 단계에서 탈락하는 이유의 상당 부분이 결합력이 아니라
흡수·분포·대사·배출·독성(ADMET)이다.

결합력만으로 순위를 매기면 **애초에 약이 될 수 없는 분자가 1위로 올라온다.**
그래서 도킹 다음에 ADMET 단계를 둔다.

이 단계는 깔때기에서 **거르는 역할**이고, 새로운 활성을 주장하는 단계가 아니다.

## 2. 도구 선정

### 비교한 선택지

| 도구 | 방식 | 재현성 | 일괄 처리 | 채택 |
|---|---|---|---|---|
| SwissADME | 웹 폼 | 버전 고정 불가 | 한 번에 소수만 | ✗ |
| pkCSM | 웹 폼 | 버전 고정 불가 | 수동 입력 | ✗ |
| RDKit 규칙 기반 (QED, Lipinski, Brenk) | 계산 규칙 | 높다 | 가능 | △ 보조 지표로만 |
| **ADMET-AI** | **D-MPNN (chemprop)** | **버전·시드 고정 가능** | **CSV 일괄** | **✓** |

### ADMET-AI 를 쓰는 이유

1. **재현성.** 과제 배점에 재현성 20점이 있고 교수가 재현을 시도한다.
   웹 폼은 모델 버전을 고정할 수 없어 같은 입력에 같은 출력을 보장하지 못한다.
   ADMET-AI 는 pip 로 버전을 고정해 설치하고 로컬에서 돌린다.
2. **일괄 처리.** 100개를 한 번에 CSV 로 넣고 받는다. 수동 입력은 기록이 남지 않는다.
3. **공개된 학습 데이터.** Therapeutics Data Commons(TDC)의 ADMET 데이터셋으로
   학습했고 벤치마크 성능이 논문에 공개돼 있다. "어디서 나온 숫자인지" 설명할 수 있다.
4. **GPU 불필요.** 로컬 CPU 로 돈다. 11/20 까지인 계산 일정에서 Colab GPU 할당량을
   도킹에만 쓸 수 있다.

### 수업 내용과의 연결 (W10 — GNN)

ADMET-AI 의 예측 모델은 **chemprop 의 D-MPNN**(Directed Message Passing Neural
Network)이다. 2단계 활성 예측에서 쓴 Morgan 지문이 **고정된 규칙으로 부분구조를
세는 방식**인 데 반해, D-MPNN 은 **원자·결합을 그래프의 노드·엣지로 보고
메시지 전달로 표현을 학습**한다.

따라서 이 프로젝트는 분자 표현을 세 계열로 쓴 셈이다.

| 계열 | 표현 방식 | 쓴 단계 |
|---|---|---|
| 지문 | 부분구조를 비트로 센다 (규칙 고정) | 2단계 활성 예측 — Morgan+RF |
| 트랜스포머 | SMILES 토큰의 문맥을 사전학습으로 배운다 | 2단계 비교군 — ChemBERTa |
| 그래프 | 원자·결합 구조에서 메시지 전달로 배운다 | 5단계 ADMET — chemprop D-MPNN |

`scripts/12_chemprop_compare.py` 에서 같은 scaffold split 으로 D-MPNN 을
CDK2 활성 예측에도 적용해 세 계열을 **동일 조건에서 비교**한다
(→ `skill/03_screening.md` 2단계 표에 합산).

### 인용

Swanson K, et al. "ADMET-AI: A machine learning ADMET platform for evaluation of
large-scale chemical libraries." *Bioinformatics.* 2024. doi:10.1093/bioinformatics/btae416

예측 항목은 **TDC ADMET 엔드포인트 41개 + RDKit 물리화학 지표 11개 = 52개**다
(`admet_ai/resources/data/admet.csv` 기준).

설치 버전: `[확인 필요: admet-ai 설치 후 버전 기록. chemprop 2.3.1 / torch 2.15.0+cpu /
rdkit 2026.03.6 환경에 올린다]`

## 3. 판정 기준 — **도킹 결과를 보기 전에 정한다**

기준을 결과를 본 뒤에 정하면 원하는 분자가 남도록 맞춘 셈이 된다.
그래서 **100개 예측을 돌리기 전에 아래 규칙을 확정하고 문서에 적어 둔다.**

### 3-1. 탈락 기준 (하드 필터)

독성 관련 분류 예측은 **확률 0.5 초과면 탈락**시킨다.
0.5 는 이진 분류의 기본 결정 경계이고, 임의로 올리거나 내리지 않았다.

| 항목 | 탈락 조건 | 이유 |
|---|---|---|
| hERG 저해 | p > 0.5 | 심장 독성(QT 연장). 개발 중단의 흔한 원인 |
| AMES 돌연변이성 | p > 0.5 | 유전독성 |
| DILI (약물 유발 간손상) | p > 0.5 | 간독성 |

### 3-2. 참고 지표 (떨어뜨리지 않고 기록만)

흡수·분포·대사는 값이 나쁘다고 곧바로 탈락시키지 않는다.
제형이나 구조 최적화로 개선되는 영역이고, 이 단계에서 잘라낼 근거가 약하다.
표에 적어 두고 최종 후보를 고를 때 함께 본다.

| 묶음 | 항목 | 보는 방향 |
|---|---|---|
| 흡수 | Caco-2 투과도, 사람 장내 흡수(HIA), 생체이용률 | 높을수록 유리 |
| 용해도 | 수용해도 logS | 높을수록 유리 |
| 분포 | 혈액-뇌 장벽(BBB), 혈장 단백 결합률(PPBR) | **BBB 는 높을 필요가 없다** (아래 참고) |
| 대사 | CYP 1A2/2C9/2C19/2D6/3A4 저해 | 낮을수록 약물 상호작용이 적다 |
| 배출 | 청소율, 반감기 | 반감기가 너무 짧으면 불리 |

**BBB 에 대한 주의**: CDK2 억제제의 주요 적응증은 HR+/HER2− 유방암이다
(`skill/01_data.md` 참조). 뇌가 표적 장기가 아니므로 BBB 투과도가 높아야 할
이유가 없고, 오히려 낮은 편이 중추신경계 부작용 위험이 작다.
**"BBB 가 낮아서 나쁘다"고 쓰지 않는다.**

### 3-3. 최종 순위 — 도킹 순위를 그대로 쓴다

하드 필터를 통과한 분자를 **4단계 도킹 순위(`rank_mean`, Vina·CNNaffinity 순위 평균)로
그대로 정렬**하고 상위 30개를 최종 후보로 제시한다.

**ADMET 지표에 가중치를 주어 도킹 순위와 섞지 않는다.** 가중치를 정할 근거가 없고,
결과를 본 뒤에 가중치를 고르면 원하는 분자가 올라오도록 맞춘 셈이 된다.
ADMET 은 **거르는 역할**만 하고 순위는 도킹이 정한다. 예측값은 표에 함께 적는다.

통과 분자가 30개 미만이면 **문턱값을 완화하지 않고** 통과한 수를 그대로 제시하고
그 개수를 보고한다.

## 4. DrugBank 승인 약물과의 비교

ADMET-AI 는 예측값을 **DrugBank 승인 약물 분포에서의 백분위**로도 돌려준다.
절대값 0.42 가 좋은지 나쁜지는 판단하기 어렵지만,
"이미 승인된 약들 중 몇 퍼센타일인지"는 해석할 수 있다.

최종 후보를 고를 때 **승인 약물 분포 범위를 벗어나지 않는지**를 함께 확인한다.
이것은 기준을 외부 자료에 맡기는 방식이라, 임의로 정한 문턱값보다 설명하기 쉽다.

## 7. 표현 주의 (보고서 작성 시 반드시 지킬 것)

ADMET 예측은 **계산 예측값이고 실험으로 측정한 약물동태·독성 자료가 아니다.**

| ✗ 쓰지 않는다 | ✓ 이렇게 쓴다 |
|---|---|
| 독성이 없는 것으로 확인됐다 | 독성 예측 확률이 기준 미만이다 |
| 안전한 화합물이다 | 예측 기준으로 탈락하지 않았다 |
| 경구 흡수가 좋다 | 흡수 예측값이 승인 약물 분포 범위 안에 있다 |
| 후보 물질을 발굴했다 | 계산 예측 기준으로 우선순위를 매겼다 |
| 최종 hit 를 선별했다 | 계산 예측 기준 상위 N개를 제시했다 |

**한계로 반드시 적을 것**
- ADMET 모델의 학습 데이터에 평가 분자가 포함됐는지 확인할 수 없다
- TDC 데이터셋은 공개 자료 기반이고 데이터가 적은 엔드포인트가 있다
- 하드 필터의 확률 문턱 0.5 는 분류 기본값이며 생물학적 근거로 정한 값이 아니다
- 이 단계까지 전부 계산 예측이고 **실험 검증은 수행하지 않았다**
